# 概要
2月8日に開催された株式会社サポーターズ様主催の【技育CAMP2025】ハッカソンVol.19に出場しました。
24チームが参加したオンライン開催のハッカソンでした。

シス研所属の1年生チームで参加し、サポーターズ賞をいただきました！

# イベントを終えて
3人とも初めて出場したハッカソンでした。
Flutter、Firebase、Raspberry Pi などを使用して開発を行いました。
初めてのチーム開発、初めて触る言語や技術を使用したので、特にバックエンドの実装に割ける時間がかなり限られました。
そのため、実装できなかった機能も出てきてしまいました。
また、テストやメンバーの体調不良など、多くの困難がありましたが、チームで一致団結してなんとか乗り越えることができました。
