# 概要
10月11日〜12日に開催された愛工大祭にて、私たちのサークルはポップコーンの模擬店を出店しました。今年は カレー・塩・キャラメル の3種類のフレーバーを販売し、多くのお客様が足を運んでくれました！
お越しいただいた皆さま、本当にありがとうございました！

# イベントを終えて
1, 2ヶ月前から準備を進め、ポップコーンの味付けや火加減を何度も試行錯誤しながら、本番ギリギリまで運営陣がしっかりと整えて当日に臨みました。
さらに、部員が1から開発したレジシステムを導入したことで、会計もスムーズに行うことができました。

1・2・3年生が協力して取り組んだ今回の模擬店は、成功とともにサークル内の絆がより深まる良い機会となりました！
