# 概要
10月10日〜11日にかけて開催された愛工大祭にて，私たちのサークルはお団子の模擬店を出店しました．
今年は，みたらし・のり醤油・あんこ・きなこの4種類のフレーバーをご用意しました．両日ともに，多くのお客様に足を運んでいただき，2日目には完売することができました．
お越しいただいた皆さま，本当にありがとうございました．

# イベントを終えて

また，昨年に引き続き,部員が開発したレジシステムを導入し，多少の改良を加えたことで，会計をよりスムーズに行うことができました．
