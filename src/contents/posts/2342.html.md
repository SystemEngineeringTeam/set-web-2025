# 概要
8/9~10に行われた株式会社サポーターズ様主催の【技育CAMP2025】ハッカソン Vol.10に出場しました。
22チームが参加したオンライン開催のハッカソンでした。

シス研所属の2年生を集めたチームで参加し、最優秀賞をいただきました！

# イベントを終えて
テスト期間と重なる日程、メンバーの体調不良など、多くの困難がありましたが、チームの結束力で乗り越えることができました。

特に、開発の追い込みとなった最後の3日間は、全員で夜通し作業を続け、互いに支え合いながら作品を完成させました。電気学科の学生がいたからこそ生まれた「ハードウェアを使った機能」が好評だったことも、チームでの開発ならではの成果だと感じています。

このチームで最優秀賞を受賞できたことを、心から嬉しく思います。


# ハッカソンで作成した作品

「音楽を聴きたいのに、手が離せない！」そんな日常の”もどかしい”を解決する、新感覚のPCアプリケーションです。

<img width="1440" alt="1.png (350.2 kB)" src="https://img.esa.io/uploads/production/attachments/19973/2025/08/12/168685/cedfe2d9-a375-49a1-a7b5-7ccd9326ba06.png">

[Gesture Audio発表スライド](https://www.canva.com/design/DAGvlxQLaRw/8fbZ3A8wx9VI0na9Rp_ppA/view?utm_content=DAGvlxQLaRw&utm_campaign=designshare&utm_medium=link2&utm_source=uniquelinks&utlId=hc4934e66f8)

腕に装着したセンサーの動きを読み取り、ジェスチャーだけで音楽を直感的に操作。作業の集中を妨げず、あなたの日常をよりリズミカルで楽しいものに変えます。
# 賞について
最優秀賞🏆
80名ほどのハッカソン参加者による投票の結果,22チーム中1位の最優秀賞を受賞しました.
